# 🧠 MINDSPACE
### Plan your time. Organize your life. Track your progress.

**MINDSPACE** is a desktop productivity application developed with Python to help students organize their tasks, manage their time, stay focused, and monitor their progress through a simple and intuitive interface.

## 🎯 Project Overview

Managing academic tasks, deadlines, and study schedules can be challenging. MINDSPACE aims to bring these activities together in one application, making personal organization easier and more efficient.

## ✨ Main Features

### ✅ Task Management
- Create, edit, and delete tasks.
- Organize tasks by category and priority.
- Set deadlines and track task status.
- Distinguish between completed and pending tasks.

### 📅 Time Planner
- Organize daily and weekly schedules.
- Visualize activities by time.
- Identify scheduling conflicts.
- Associate tasks with planned time slots.

### ⏱️ Focus Mode
- Use a timer for focused work sessions.
- Track the time spent on individual tasks.
- Review focus session durations.

### 📝 Mini Quizzes
- Answer short quizzes on different subjects.
- Calculate quiz scores.
- Review previous results and monitor performance.

### 📊 Progress Dashboard
- View task completion statistics.
- Track daily and weekly activity.
- Compare planned time with actual time spent.
- Review quiz results.

### 💾 Data Storage
- Save tasks, schedules, and results locally.
- Keep information available between application sessions using JSON files.

## 🛠️ Technologies

- **Python** — Application logic
- **Tkinter** — Graphical user interface
- **JSON** — Local data storage
- **datetime / time** — Date, schedule, and timer management
- **Matplotlib (optional)** — Data visualization and statistics
